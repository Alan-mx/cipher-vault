## Regeneration Rule

Do not regenerate this fixture from the current working tree. It was produced
before production changes for this compatibility baseline and must remain
frozen so later versions can prove they can read a backup generated by the
baseline program.

`GenerateBackupCompatibilityFixtureTests.GenerateSchema5BackupFixture` is
skipped by default and is retained only as a manual generation reference. If a
future release needs a new fixture for a genuinely new published Schema/format
combination, create a new directory and metadata file rather than overwriting
this one.
